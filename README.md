# Trends-in-the-IT-and-data-industry
Apply NLP processing techniques, visualize data and identify trends in the IT, data industry.

## Installation Guide

### Prerequisites
- Python 3.8 or higher
- jupyter

### Step 1: Clone the Repository
```bash
git clone https://github.com/zombieTDV/Trends-in-the-IT-and-data-industry.git
cd Trends-in-the-IT-and-data-industry
```

### Step 2: Create Virtual Environment
```bash
# Create virtual environment
python -m venv .venv
```

# Activate virtual environment
#### On Windows:
```bash
.venv\Scripts\activate.bat
```
#### On macOS/Linux:
```bash
source .venv/bin/activate
```

### Step 3: Install Dependencies
```bash
pip install -r requirements.txt
```
